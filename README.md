Project Idea: Online Shopping System

The project idea is to develop an Online Shopping System that enables customers to view available products, manage their shopping carts, place orders, and make payments. The system also allows administrators to manage products and organise them into categories.

The purpose of this project is to model the structure of an online shopping platform using a UML class diagram, showing the main classes, their attributes, methods, relationships, and multiplicities.
 3. Project Description

The Online Shopping System is a proposed e-commerce system that allows customers to view products, manage their shopping carts, place orders, and make payments. Administrators manage products and product categories.

This project uses a Unified Modeling Language (UML) class diagram to represent the system's structure, including its classes, attributes, methods, relationships, and multiplicities.

 4. Problem Statement

Traditional shopping requires customers to visit physical shops to find and purchase products. Managing customers, products, shopping carts, orders, and payment information can also be challenging without an organised system.

The proposed Online Shopping System models the main components of an online shopping platform to demonstrate how they can be structured and related.

5. Project Objectives

The main objectives are to:

 Identify the main classes required for an online shopping system.
 Define the attributes and methods of each class.
 Represent relationships between classes using UML notation.
 Specify multiplicities between related classes.
 Develop a UML class diagram that explains the system's structure.

 6. Project Scope

The project focuses on modelling the following activities:

 Customer information and registration.
 Product management.
 Product categorisation.
 Shopping cart management.
 Order placement and management.
 Payment-related information.

The project focuses on UML modelling rather than implementing a complete, working online shopping application.

 7. Main Classes

The diagram contains seven main classes:

Class          Responsibility
Admin : Manages products in the system. 
 Customer : Stores customer information and supports registration and updates. 
 Product : Represents products available for customers to view and purchase. 
 Category : Organises products into categories. 
 Cart  :Represents the customer's shopping cart. 
 Order : Represents orders placed by customers. 
 Payment : Represents payment-related information. 

8. Relationships Between Classes

The UML class diagram represents relationships between the main classes:

 Admin manages products.
 Customer views products and places orders.
 Customer is associated with a shopping cart.
 Cart is associated with products selected for shopping.
 Category organises products.
 Order is associated with payment-related activities.

Multiplicity notation indicates how many instances of one class can be associated with another.
